Hey guys, this will be my last post of 2016!

This time I will show you my desktop, it's not perfect but I'm productive with it.

**Let's start with a clean workspace**

![Clean Workspace](/assets/media/20161231_desktoptour/clean_workspace.png)

As you can see it looks pretty simple, a top bar with the information and a clean desktop.
The bar you see on top is i3bar, the content in the bar is provided by a shell script I made.

---

**Fake busy**

![Fake Busy](/assets/media/20161231_desktoptour/fake_busy.png)

As you may noticed I use a tilling window manager, i3.
There's a floating window with screenfetch with some details on my configuration.

I use **zsh** as my shell, bash is fine too but there are a lot of nice plugins for zsh.

Software in this screenshot:

 - Weechat - IRC client
 - SimpleRSS - RSS Reader (Check my previous post for more info)
 - Ranger - A cool File Manager with image support


Other terminal softwares I use:

 - Cgo - Gopher Browser
 - Vim - Text Editor (Mostly for development)
 - Mutt - For e-mails
 - w3m - For some webbrowsing
 - Scripts, a lot of scripts!

**The Browser - Firefox**

![Fake Busy](/assets/media/20161231_desktoptour/vimperator.png)

I use firefox with **vimperator** and **stylish** (yes, I am a Vim addict).

My Firefox theme is a slightly modified version of [Twilly Firefox.css](http://twily.info/firefox/stylish/firefox-css)
