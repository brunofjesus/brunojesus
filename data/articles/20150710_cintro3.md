We have already talked about variables and constants, now we will talk about type modifiers. The type modifiers define the memory reserved for the variable/constant.

In C we have the following modifiers:

 - Signed - The variable can store positive and negative values. 
 	- This is the C default so you don't need to explicitly declare that the variable is signed
	- Examples:
	  - `signed int temperature;`
	  - `int temperature;`
 - Unsigned - The variable can only store non-negative values.
 	- Example: `unsigned int salary;`
 - Long - Extends the length of the variable, (by default an `int` is typically 4 bytes, a `long int` is at least 4 bytes and is 8 bytes on 64-bit Linux and macOS)
   - Example: `long int myHugeNumber;`
 - Short - Does the opposite of `long` (by default an `int` is typically 4 bytes, a `short int` is typically 2 bytes)
   - Example: `short int age;`


## Int
 - All of the mentioned type modifiers can be used in `int` variables as seen in the examples above.

## Char
 - Char can only be signed or unsigned.
 - When signed have a range from -128 to 127
 - When unsigned they have a range from 0 to 255

## Float and double
 - You can use the `long` modifier for the `double` type, this will extend the precision of the floating point number.
 - Ordered by precision (smallest to biggest):
   - float
   - double
   - long double


## Printing the sizes of our data types

```c
#include <stdio.h>
 
int main()
{    
  printf("int : %zu bytes\n", sizeof(int) );
  printf("short: %zu bytes\n", sizeof(short) );
  printf("long: %zu bytes\n", sizeof(long) );
  return 0;
}
```

**Suggestion:** Try this code with other data types.
