This is the second part of our tutorial, this time we will make a simple Hello World and talk about Variables and Constants.

## Hello World
The Hello World is a little program that simply prints Hello World in the screen, here is the code.

```c
#include<stdio.h>
int main()
{
  printf("Hello World\n");
  return 0;
}
```

### What's the meaning of this?
 - **#include<stdio.h>** - Imports the stdio library.
   - The #include is used to import the functions of a library to our program, I know it's confusing, we will get into that later.
   - The stdio.h is a library, this library makes it possible to make Input/Output operations like write to screen and read user input. You can check all stdio functions [here](http://www.techonthenet.com/c_language/standard_library_functions/stdio_h/).
   - You can also read the man page for stdio with `man 3 stdio`, if using Arch you first need to install the [man-pages](https://archlinux.org/packages/core/any/man-pages/) package.
 - **int main()** - This is the name of the main function all the content between {} belongs to this function.
   - The **int** stands for integer and in this case it defines what type of value the function will return. We will talk about this later.
   - **printf("Hello World\n");** - This instruction prints **Hello World** to screen, the **\n** is the newline character, any text printed after **\n** will appear in the next line.
   - **return 0;** - It's the result of the function, the return value must match the type of the function.


## Variables and Constants
When you declare a variable or a constant you are reserving a memory address, you can use these address to store values.
When you declare a variable or a constant you have to assign them a name, to access it later you have to call it by the name you've assigned.

### Data Types 
Today I will only talk about fundamental data types, we will get deeper into data types later.

 - **int** - Integer number. Its size depends on the platform, but it is typically 4 bytes on modern computers, ranging from -2147483648 to +2147483647. (The C standard only guarantees 2 bytes, -32768 to +32767.)
   - Example: int year = 2015;
 - **float** - Real numbers like 1.45, 3.14, -45.3 etc. It has a precision of 6 digits.
 - **double** - Like `float` but has a precision of 15 digits.
 - **char** - Character. can store a single character (1 byte).
   - Example: 
     - char letter = 'a';
	 - char letter = 97;
	 - The above examples are the same thing, 97 is 'a' in the ASCII table
 - ***bool*** - Boolean values, can store TRUE or FALSE.
   - C doesn't support booleans by default but we can implement them, we will do that in the next sessions.

## Variables
Variables are used to store values, you can think of a variable like a little box where you can store one thing (a number for example), you can change the value of the variable along the code.

You declare variables this way: `type name;`, you can also assign a value while declaring: `type name = value`.

### Let's add some apples to our Hello World:

```c
#include<stdio.h>

int main()
{
  int apples = 12; //This is the variable apples and 12 is its value.
  printf("Hello World\n");
  printf("I have %d apples\n", apples);
  	
  apples = apples + 1; //We add an apple
  printf("Now I have %d apples\n", apples);
  
  return 0;
}
```

The `//` is used to make comments on the code, comments are not interpreted by the compiler.

**Suggestion:** Use **camel case** for the variable names, in camel case each word begins with a capital letter except the first one, like `grayApples` and `messageContent`.

## Constants
Constants are used to store **constant** values, this means that after you declare a constant you cannot change its value.

### Examples of constants in C:

You can declare constants almost the same way you declare variables, the only difference is the use of the `const` keyword.

```c
#include<stdio.h>
int main()
{
  int const AGE = 22;
  const int YEAR = 2015;
  const char NEWLINE = '\n';
  ...
```

You can also define a constant in the preprocessor:

```c
#include<stdio.h>
#define AGE 22
#define NEWLINE '\n'

int main()
{
...
```

The last one may seem confusing to you, you can think of if like a Search and Replace operation, before the compilation (the process of converting your code to machine code) the C compiler replaces all occurrences of AGE for 22 and NEWLINE for '\n'. In this way the constant isn't stored in memory because the constant name was replaced by its value in the compiled code.

### Our apples are constants now:

```c
#include<stdio.h>

#define BASKETS 2
int main()
{
  const int APPLES = 12;
  printf("Hello World\n");
  printf("I have %d apples in %d baskets", APPLES, BASKETS);
  return 0;
}
```

The %d is a format specifier, you use the format specifiers as "placeholders", and then you pass the values as arguments. 

Normally you use `type const` or `const type` if you want to use the constants inside the function.

If you want your constants to be used in the whole program you may use the `#define`.

**Suggestion:** It's a good practice to name your constants in **UPPERCASE** this way you won't confuse constants with variables while coding.

## Naming Restrictions
You can't give any name to a variable, all names must obey to all these rules:

 - Can't start with numbers
 - Can't be equal to reserved keywords
 - Can't have spaces
